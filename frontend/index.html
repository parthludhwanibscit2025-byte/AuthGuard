What We Built

Six core security capabilities in one working prototype

🔐

Secure Authentication

Registration & login with bcrypt password hashing and JWT tokens. Passwords are never stored in plain text.

👥

Role-Based Access Control

Three roles — Admin, Manager, User. Server-side middleware enforces permissions on every protected route.

📊

Adaptive Risk Engine

Calculates risk score from failed attempts, device trust, location and sensitive-action flags. Returns Low / Medium / High.

🔒

Account Lockout

After 5 failed logins the account is temporarily locked for 15 minutes, preventing brute-force attacks.

📝

Audit Logging

Every login, registration and security event is recorded with timestamp, username, IP and outcome for review.

🖥️

Interactive Dashboard

Live web UI to test login, risk evaluation, role-protected resources, admin stats and audit logs in real time.

Suggested Faculty Demo Flow

  1. Login as User (demo) → show profile and that Admin resource is denied (403).
  2. Logout → Login as Manager (parth) → show Manager resource works, Admin still denied.
  3. Login as Admin (yug) → open Admin resource, Stats and Audit log.
  4. Risk Engine → set Device = unknown, Location = unusual, Sensitive = on → score jumps to High.
  5. Lockout → intentionally enter wrong password 5 times on any account to demonstrate temporary lock.
  6. Register a new user to show validation and bcrypt hashing in action.
