# AuthGuard Project Status

## Completed in this prototype
- Registration API
- Login API
- bcrypt password hashing
- JWT authentication
- Admin / Manager / User roles
- Server-side RBAC middleware
- Protected resources
- Adaptive risk engine
- Failed-login monitoring
- Temporary account lockout
- Audit logging
- Dashboard connected to REST APIs
- API test examples
- Basic automated tests

## Suggested next phase
1. Replace JSON persistence with MySQL/PostgreSQL.
2. Implement real TOTP or WebAuthn MFA.
3. Add refresh-token rotation/revocation.
4. Add request validation with a schema library.
5. Add rate limiting and security headers.
6. Add CI/CD and test coverage.
7. Deploy behind HTTPS.
8. Add screenshots and live API demonstration to the final college report/PPT.
